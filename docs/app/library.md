# Library

## Overview

Library settings control the order of the battle config list. You can reorder the server tabs, hide the tabs that you do not use, and select a sort method.

The Library section holds two settings: **Library Tabs** and **Sort Configs**.

## Key Features

### Customize the server tabs

Tap **Library Tabs** to open a pane with one row for each server. The row order is the order of the tabs in the Library tab bar.

| Action | How to do it |
| ------ | ------------ |
| Change the order | Drag the handle icon on a row. Only a visible tab can move |
| Hide or show a tab | Tap the visibility icon on the row. The icon changes between an open eye and a closed eye |

A hidden tab shows dimmed text, and its handle does not move. Tap the visibility icon again to show the tab.

The **Default** tab shows every config, regardless of the server of each config. You cannot hide the **Default** tab, so FGA disables the visibility icon on that row.

The available servers are:

| Server  | Description                                      |
| ------- | ------------------------------------------------ |
| Default | Shows every config                                |
| NA      | The North America / Global server                 |
| JP      | The Japanese server                               |
| CN      | The Chinese server                                |
| TW      | The Taiwan server                                 |
| KR      | The Korean server                                 |

!!! note "BetterFGO variants"
    The BetterFGO variants of NA and JP use the same tab as their base server.

### Select a sort method

Tap **Sort Configs** to open a list of options. The list in the Library then uses the selected order.

| Sort option   | Order                                                          |
| ------------- | -------------------------------------------------------------- |
| Name (A-Z)    | Alphabetical order, from A to Z                                |
| Name (Z-A)    | Alphabetical order, from Z to A                                |
| Recently Used | The config that you used last comes first                       |
| Oldest Used   | The config that you did not use for a long time comes first     |
| Most Used     | The config with the highest run count comes first               |
| Least Used    | The config with the lowest run count comes first                |

The sort applies to every tab, and FGA keeps your selection between sessions.

## Tips for Best Results

- Hide the servers that you do not play. The Library tab bar then stays short.
- Put your main server in the first position after the **Default** tab. You then reach that tab with one swipe.
- Use **Recently Used** when you switch between a small set of configs.
- Use **Most Used** to keep your main farming configs at the top of the list.

## Troubleshooting

| Problem | Solution |
| ------- | -------- |
| A hidden tab still shows | Tap the visibility icon again. The row must show the tab as hidden. Then return to the Library. |
| A tab does not move | Only a visible tab can move. Tap the visibility icon to show the tab. Then drag the handle. |
| A config is in the wrong tab | Go to another tab and return. Close and open FGA if the server of the config changed. |
| The sort order looks wrong | Open **Sort Configs** and select the order again. The list updates at once. |
